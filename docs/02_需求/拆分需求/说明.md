## 规则

1. 本目录中的“架构对齐决策”和“补充验收要求”是后续实现基线；当它们与原始需求存在冲突时，以基础能力平台架构文档为准。
2. 合同管理系统是基础能力平台中的一个 `Application` 消费者，不直接操作 IAM、授权、审计、配置等平台表。
3. 平台内部为 Go + Vue 的模块化单体、MySQL 主库；不使用 Redis；文件保存到受控本地/挂载目录，数据库只保存元数据与绑定关系。
4. 业务模块通过标准协议、REST API 或 SDK 使用平台能力；跨系统审计通过本地 `audit_outbox` 上报，不能直连平台审计表。
