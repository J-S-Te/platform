# 06 统计与查询需求

## 1. 领域边界

统计报表属于合同模块的查询能力。指标口径、筛选条件、时间范围和数据范围必须明确；图表仅展示经授权的数据聚合结果。

## 2. 架构对齐后的补充要求

- 每个统计接口应用同一数据范围逻辑，不能只在列表接口鉴权。
- 指标查询与导出需要记录审计事件；大导出采用异步导出任务并保存任务与文件绑定。
- 查询读取合同业务表或专用汇总表；运行日志、Trace、Metric 不写入 MySQL 业务表。
- 仪表盘权限应规范为 `contract:dashboard:read`；到期查询权限建议为 `contract:contract:read` + 相应数据范围，不使用含糊的跨域 `approval.view`。

## 3. 原始需求摘录（完整保留）

### STA-001 仪表盘

| 功能编号 | STA-001 |
|---------|---------|
| 对应页面 | 仪表盘（/dashboard） |
| 功能描述 | 系统首页展示关键数据统计，为用户提供业务全貌。 |

#### 一、页面元素（基于 ECharts 可视化）

| 组件/控件 | 说明 |
|----------|------|
| 总合同数统计卡片 | 展示合同总数 |
| 各状态合同数量统计 | 各状态数量（草稿/待审批/已批准/已生效/执行中/待付款/已完成/已终止/已归档） |
| 合同金额汇总 | 合同总金额统计 |
| 月度金额趋势图 | 按月统计合同金额趋势（ECharts 折线图） |
| 合同类型分布饼图 | 各类型合同分布（ECharts 饼图） |
| 即将到期合同数量 | 到期合同数量 |
| 待审批合同数 | 审批角色可见的待审批数量 |
| 待审批状态变更数 | 管理员/销售负责人可见的数量 |

#### 二、操作步骤

| 步骤 | 操作说明 |
|------|----------|
| 1 | 用户登录后默认跳转仪表盘（需 `dashboard` 权限） |
| 2 | 页面加载时从后端 API（`/api/statistics`）获取统计数据 |
| 3 | 统计数据根据当前用户角色自动过滤 |
| 4 | 管理员可查看全部数据，普通用户仅查看自己相关的 |
| 5 | 用户可点击统计卡片跳转至对应功能页面 |

#### 三、技术约束

| 约束项 | 说明 |
|--------|------|
| 数据来源 | 数据实时从后端 API（`/api/statistics`）获取 |
| 图表渲染 | 图表使用 ECharts 渲染 |
| 访问权限 | 仪表盘需 `dashboard` 权限 |
| 数据权限 | 统计数据根据当前用户角色自动过滤 |

### STA-002 即将到期合同查询

| 功能编号 | STA-002 |
|---------|---------|
| 对应页面 | 到期提醒页 |
| 功能描述 | 查询指定天数内即将到期的合同列表，便于业务人员及时跟进。 |

#### 一、页面元素

| 组件/控件 | 说明 |
|----------|------|
| 即将到期合同列表 | 合同编号、标题、客户、金额、结束日期、剩余天数 |
| 到期天数参数 | 默认 30 天可在请求中配置 |

#### 二、操作步骤

| 步骤 | 操作说明 |
|------|----------|
| 1 | 用户指定提前天数（默认 30 天） |
| 2 | 系统查询结束日期在指定天数范围内的合同 |
| 3 | 返回合同列表（编号、标题、客户、金额、结束日期） |

#### 三、技术约束

| 约束项 | 说明 |
|--------|------|
| API接口 | `/api/expiring-contracts?days=N` |
| 访问权限 | 需 `approval.view` 权限 |
| 数据权限 | 根据角色权限显示不同范围的数据 |
