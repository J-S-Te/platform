# 02 客户与相对方需求

## 1. 领域边界与实现约束

客户/供应商信息为合同业务域的相对方主数据，不属于基础能力平台 IAM 模块。其数据表建议归属 `contract` 模块（例如 `contract_counterparty`），并带 `tenant_id`、状态、创建/更新人、版本号。

- 合同、模板、审批、台账只引用相对方稳定 ID 与展示名快照。
- 客户信用等级等审批规则输入应使用可审计的字段版本，规则执行时保存命中快照。
- 对相对方的新增、编辑、启停、导出等操作必须产生合同应用审计事件。
- 查询结果需叠加数据范围；不能仅依赖前端隐藏按钮。

## 2. 建议权限资源

| 权限编码 | 含义 |
|---|---|
| `contract:counterparty:read` | 查询客户/供应商 |
| `contract:counterparty:create` | 新建相对方 |
| `contract:counterparty:update` | 编辑相对方 |
| `contract:counterparty:disable` | 启停相对方 |
| `contract:counterparty:export` | 导出相对方信息 |

## 3. 原始需求摘录（完整保留）

### CUS-001 客户/供应商信息查询

| 功能编号 | CUS-001 |
|---------|---------|
| 对应页面 | 客户管理页（/customers） |
| 功能描述 | 用户可提交客户及供应商信息查询请求，系统调用外部系统接口返回查询结果，展示客户编码、名称、类型、联系人、联系电话、信用等级等信息。本模块仅提供查询展示功能，数据维护由其他系统负责。 |

#### 一、页面元素

| 组件/控件 | 类型 | 说明 |
|----------|------|------|
| 查询条件区域 | 表单控件 | 支持按客户编码、名称、类型（客户/供应商）、信用等级等条件查询 |
| 查询按钮 | 操作按钮 | 提交查询请求，调用外部系统接口 |
| 查询结果列表 | 数据表格 | 展示外部系统返回的客户/供应商信息（编码、名称、类型、联系人、电话、信用等级、状态） |
| 分页控件 | 分页器 | 分页显示查询结果 |
| 详情查看按钮 | 操作按钮 | 查看客户/供应商详细信息（弹窗展示，数据来自外部系统） |

#### 二、操作步骤

| 步骤 | 操作说明 |
|------|----------|
| 1 | 用户（需 `customer.read` 权限）进入客户管理页面 |
| 2 | 用户填写查询条件（支持模糊查询、多条件组合查询） |
| 3 | 用户点击「查询」按钮，系统调用外部系统接口 |
| 4 | 外部系统返回查询结果（JSON 格式），系统解析并展示在列表中 |
| 5 | 用户可点击「详情」查看具体信息（弹窗展示，数据来自外部系统，只读展示） |
| 6 | 查询操作记录审计日志 |

#### 三、技术约束

| 约束项 | 说明 |
|--------|------|
| 数据来源 | 客户/供应商数据由外部系统维护，本系统仅提供查询展示功能，不支持新增、编辑、删除操作 |
| 接口调用 | 通过 API 接口（如 `/api/external/customers`）调用外部系统，返回 JSON 格式数据 |
| 查询权限 | 需 `customer.read` 权限 |
| 审计日志 | 所有查询操作记录审计日志（查询条件、返回记录数、操作人、操作时间） |
| 数据缓存 | 可选：对频繁查询的数据进行短期缓存（如 5 分钟），减少外部系统调用压力 |
| 错误处理 | 外部系统不可用时，展示友好错误提示，并记录错误日志 |
