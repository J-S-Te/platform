# 基础能力平台前端

当前阶段提供统一登录页，以及仅包含**系统设置**、**审计日志**的基础能力平台控制台；技术栈为 **Vue 3 + JavaScript + Vite**。

## 本地运行

以下命令默认在 Linux Bash 中从项目根目录执行；依赖安装使用锁文件，不使用 `npm install` 更新依赖版本：

```bash
cd frontend
npm ci
npm run dev
```

访问：

- `http://localhost:5173/`：系统设置（默认首页）
- `http://localhost:5173/audit`：审计日志
- `http://localhost:5173/login.html`：统一登录页

## 构建

```bash
cd frontend
npm run build
```

构建产物位于 `frontend/dist/`，仅作为本地或部署构建结果使用，不提交到版本库。

如需清理 Linux 工作区，从项目根目录执行 `rm -rf frontend/node_modules frontend/dist frontend/.vite`。

## 登录接口约定

页面默认调用：

```text
POST /api/v1/auth/login
Content-Type: application/json

{
  "account": "用户名、手机号或邮箱",
  "password": "用户输入的密码",
  "login_type": "password"
}
```

推荐后端通过 `HttpOnly + Secure + SameSite` Cookie 下发会话凭证。前端不会把 access token 或 refresh token 写入 `localStorage` / `sessionStorage`，仅在用户勾选“记住账号”后保存账号名。

可复制 `frontend/.env.example` 为 `frontend/.env.local`，修改 API 地址和登录成功跳转地址。

原始静态页面已归档为当前文档目录下的[首页参考原型](原型/首页参考原型.html)和[登录参考原型](原型/登录参考原型.html)。这些文件仅用于视觉参考，不参与 Vite 运行或构建。

## 目录结构

```text
frontend/src/
├── modules/
│   ├── platform/                # 基础平台子模块
│   │   ├── app/                 # 平台根组件与装配
│   │   ├── auth/                # 统一登录、MFA 与扫码登录
│   │   ├── iam/                 # 用户、组织、角色与权限
│   │   ├── login-targets/       # 统一登录目标注册
│   │   ├── notifications/       # 站内通知
│   │   ├── audit/               # 审计基础能力
│   │   ├── observability/       # 日志、Trace、Metric 与告警
│   │   ├── security/            # 登录安全与风险策略
│   │   ├── files/               # 文件与异步任务
│   │   ├── shared/              # 平台内部复用组件与样式
│   │   ├── views/               # 平台控制台页面
│   │   └── styles/              # 平台控制台样式
│   ├── contract_management/     # 合同管理子模块（待实现）
│   └── project_management/      # 项目管理子模块（待实现）
└── main.js                      # 浏览器入口
```

三个顶层子模块平行维护。每个业务子模块可按需包含 `api/`、`components/`、`views/`、`styles/`、`utils/` 和 `routes.js`；模块内部代码就近存放。未来确实被多个顶层子模块共同使用的内容可提取到 `src/shared/`。

## 系统边界

本仓库采用单仓库、单前端应用组织基础平台与业务子模块。`platform` 提供统一登录以及 IAM、审计、通知、可观测性、文件任务等公共能力；合同管理、项目管理和后续业务模块作为 `src/modules/` 下的平行子模块接入。业务模块可以依赖平台公共能力，平台模块不得反向依赖具体业务模块。

## 当前页面范围

本次仅实现系统设置与审计日志两个页面。其中系统设置已包含**用户与角色**标签：用户、登录账号、角色、角色绑定和数据范围均按平台模型展示。

审计记录、系统设置以及用户与角色数据当前均为前端示例状态：筛选、查看详情、账号或角色状态切换和导出交互可用；持久化将在 Go 单体应用接口与 MySQL 模型接入后实现。
