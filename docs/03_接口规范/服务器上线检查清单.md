## 2. 发布前审批

- [ ] 发布范围、接口变更和数据库迁移已评审；
- [ ] 发布产物来自固定提交并具有 SHA-256 校验值；
- [ ] 已在预发布环境完成相同迁移和冒烟测试；
- [ ] 已明确数据库恢复负责人和回退决策人；
- [ ] 已通知受影响的接入系统；
- [ ] 已确认发布期间是否需要维护窗口。

## 3. 服务器与网络

- [ ] Linux 版本和 CPU 架构符合构建产物；
- [ ] `timedatectl status` 显示时钟同步正常；
- [ ] CPU、内存、磁盘和文件句柄余量满足发布要求；
- [ ] 80/443 对外可用，8080/3306 不暴露公网；
- [ ] SSH 仅允许受控来源和密钥登录；
- [ ] DNS 已指向正确入口；
- [ ] HTTPS 证书有效且已配置续期告警；
- [ ] Nginx/网关能访问 Gin API；
- [ ] API/Worker 能访问 MySQL；
- [ ] 如启用外部登录，服务器出网白名单已放行目标主机。

## 4. 配置与密钥

- [ ] 生产配置不在 Git 仓库内；
- [ ] 配置文件权限为 `0640` 或更严格；
- [ ] JWT 私钥权限为 `0600`；
- [ ] `APP_ENV=production`；
- [ ] `APP_PUBLIC_BASE_URL` 是最终 HTTPS Origin；
- [ ] `OIDC_ISSUER` 已留空以复用 `APP_PUBLIC_BASE_URL`，或已配置为最终 HTTPS Origin；
- [ ] `AUTH_SESSION_COOKIE_SECURE=true`；
- [ ] SameSite 与部署域名方案匹配；
- [ ] CORS 只包含精确可信 Origin，不包含 `*`；
- [ ] 数据库密码来自受控密钥系统；
- [ ] JWT 密钥已备份并能恢复；
- [ ] 手机号、MFA、身份提供商、外部登录状态四类密钥互不相同；
- [ ] 所有 API/Worker 实例使用相同密钥；
- [ ] 多个 Worker 的 `ASYNC_WORKER_ID` 唯一；
- [ ] `IAM_BOOTSTRAP_TOKEN` 仅在首次初始化期间临时存在。

## 5. 数据库和文件

- [ ] MySQL 是受支持的 Oracle MySQL 8.x；
- [ ] 数据库字符集为 `utf8mb4`；
- [ ] 发布前数据库备份成功；
- [ ] 最近一次恢复演练结果可查；
- [ ] 迁移账号拥有所需 DDL/DML 权限；
- [ ] 运行账号权限已按最小权限核对；
- [ ] `FILE_STORAGE_ROOT` 已持久化并可由 API/Worker 写入；
- [ ] 上传文件已备份；
- [ ] 数据库和文件备份恢复点一致；
- [ ] 日志、上传和数据库磁盘均有容量告警。

## 6. 构建和发布产物

- [ ] `gofmt -l .` 无输出；
- [ ] `go mod verify` 成功；
- [ ] `go vet ./...` 成功；
- [ ] `go test ./...` 成功；
- [ ] `npm ci` 成功且未修改锁文件；
- [ ] `npm test` 成功；
- [ ] `npm run build` 成功；
- [ ] 后端二进制架构与目标服务器一致；
- [ ] `index.html`、`login.html` 和静态资源存在；
- [ ] 服务器上的 `sha256sum -c SHA256SUMS` 成功；
- [ ] 上一个可回退版本仍保留。

## 7. 迁移和启动

- [ ] 发布前再次确认数据库备份；
- [ ] 只有一个迁移任务执行；
- [ ] 迁移程序成功退出；
- [ ] `platform_schema_migration` 版本和校验和正确；
- [ ] API 由 systemd 或容器编排托管；
- [ ] Worker 由 systemd 或容器编排托管；
- [ ] API `/healthz` 成功；
- [ ] API `/readyz` 成功；
- [ ] Worker 日志显示数据库连接和任务循环正常；
- [ ] Nginx 配置检查成功；
- [ ] 前端静态目录已切换到新版本。

## 8. 功能冒烟

- [ ] 首页和登录页可访问；
- [ ] Vue Router 子路由刷新不返回 404；
- [ ] 本地账号登录、刷新和退出正常；
- [ ] Secure Cookie 已写入且不会通过 HTTP 发送；
- [ ] MFA 登录正常；
- [ ] 高风险操作二次验证正常；
- [ ] 用户、角色、权限查询正常；
- [ ] 无权限访问能正确返回 403；
- [ ] 审计列表和事件详情正常；
- [ ] 应用审计上报鉴权正常；
- [ ] 文件上传、下载权限和清理正常；
- [ ] 站内信列表和已读操作正常；
- [ ] OIDC Discovery 和 JWKS 可访问；
- [ ] Authorization Code + PKCE 和 Logout 正常；
- [ ] 如启用外部 OIDC，已完成真实登录；
- [ ] 如启用钉钉，已完成真实扫码和 MFA 衔接。

## 9. 安全和审计

- [ ] API、MySQL 和 Docker Socket 未公开；
- [ ] Nginx 已传递 Host、真实来源地址和 HTTPS 协议信息；
- [ ] 代理上传限制与应用 20 MiB 限制匹配；
- [ ] 首次管理员初始化后已删除 `IAM_BOOTSTRAP_TOKEN` 并重启 API；
- [ ] 首个管理员已修改初始密码并启用 MFA；
- [ ] 日志中没有密码、Cookie、Token、密钥、授权码和 TOTP 种子；
- [ ] 登录失败、管理员操作和配置变更产生审计事件；
- [ ] 网关/WAF 已覆盖多实例统一限流需求；
- [ ] 配置、密钥和备份访问均有审计记录。

## 10. 监控和备份

- [ ] `/healthz` 和 `/readyz` 已接入监控；
- [ ] API 5xx、401、403、429 已接入告警；
- [ ] MySQL 连接、慢查询、磁盘和备份已监控；
- [ ] Worker 任务积压和失败已监控；
- [ ] 日志文件已配置轮转和集中采集；
- [ ] 上传目录磁盘已配置阈值告警；
- [ ] TLS 证书已配置到期告警；
- [ ] 外部身份提供商失败率已监控；
- [ ] 本次发布后的数据库和文件备份计划已确认。

## 11. 回退准备

- [ ] 上一个 API、Worker 和前端产物可用；
- [ ] 已确认旧版本与新数据库结构兼容；
- [ ] 数据库没有自动 down migration，团队已明确前滚修复或恢复备份方案；
- [ ] 回退时不会替换 JWT 和应用加密密钥；
- [ ] 回退命令已由第二人复核；
- [ ] 回退后的健康检查和冒烟项已明确。
