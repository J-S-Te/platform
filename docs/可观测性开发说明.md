# 可观测性开发说明

## 1. 模块边界

本模块基于 Gin + GORM + MySQL，负责运行日志、Trace、Metric、告警规则、告警评估和站内信联动，不承担不可变业务审计。

- 不使用 Redis；
- 运行日志、Trace、Metric 使用 API 进程内有界存储，运行日志可同步写入受控 JSONL 文件；
- 告警规则、执行状态和评估记录使用 MySQL 持久化；
- 遥测属性递归脱敏 `password`、`token`、`secret`、`cookie`、`authorization` 等敏感键；
- 不采集请求体、Cookie 值、Authorization 值和查询字符串。

进程内遥测适用于当前单体和单实例运行验证，不等同于多实例集中式观测平台。后续若要求跨实例统一查询，应新增受控 OTLP/集中存储适配器，不能把高频 Trace/Metric 直接无界写入业务 MySQL。

## 2. 已实现能力

### 2.1 运行采集与查询

`TelemetryService` 已实现：

- `RecordLog`、`RecordSpan`、`RecordMetric`；
- `QueryLogs`、`QueryTraces`、`QueryMetrics`；
- 租户、应用、Trace ID、Request ID、时间范围等条件过滤；
- 有界内存存储与 JSON 文件 Sink；
- W3C `traceparent` 校验、生成和响应回传。

Gin 遥测中间件已在共享 Router 中注册。对可信租户请求采集服务端 Span、运行日志及 HTTP 请求量、错误量和耗时指标，不影响原业务响应。

### 2.2 告警规则与站内信联动

告警规则支持创建、列表、乐观锁更新、单规则执行和周期执行。阈值运算支持 `GT`、`GTE`、`LT`、`LTE`，并实现：

- 首次触发通知；
- 重复通知间隔；
- 间隔内抑制；
- 告警恢复通知；
- 通知失败评估记录；
- 规则状态和评估记录持久化。

`stationNotificationAdapter` 已接入通知应用服务，只投递站内信。它按需创建并启用 `OBSERVABILITY_ALERT` 模板，不发送邮件、短信或 Webhook。

由于当前 Metric 数据在 API 进程内，`AlertRunner` 随 API 生命周期启动，而不是放入独立 Worker；否则独立进程无法读取 API 内存中的样本。

## 3. 已注册接口

| 方法 | 路径 | 权限 |
| --- | --- | --- |
| `GET` | `/api/v1/observability/logs` | `platform:observability:log:view` |
| `GET` | `/api/v1/observability/traces` | `platform:observability:trace:view` |
| `GET` | `/api/v1/observability/metrics` | `platform:observability:metric:view` |
| `GET` | `/api/v1/observability/alert-rules` | `platform:observability:alert:manage` |
| `POST` | `/api/v1/observability/alert-rules` | `platform:observability:alert:manage` |
| `PATCH` | `/api/v1/observability/alert-rules/{rule_id}` | `platform:observability:alert:manage` |
| `POST` | `/api/v1/observability/alert-rules/{rule_id}:execute` | `platform:observability:alert:execute` |

相关表由 `000033_create_observability_alerts.sql` 创建，资源和权限由 `000034_seed_platform_operations_permissions.sql` 初始化。OpenAPI 已同步。

## 4. 前端

`ObservabilityManagementModule.vue` 已挂载到 `PlatformConsoleView.vue`，提供运行日志、Trace、Metric 与告警规则视图，调用真实接口，不使用伪造数据。现有旧版安全可观测组件中的通知渠道文案已收敛为站内信，不再展示邮件或短信发送能力。

## 5. 当前限制

- Trace、Metric 和可查询运行日志仍是进程本地有界数据，重启后不会恢复；
- 多实例之间不共享遥测样本；
- `OTEL_*` 配置已保留，但当前未实现真实 OTLP 导出；
- 尚未进行接入外部观测后端后的容量、采样、保留期和故障降级验收。
